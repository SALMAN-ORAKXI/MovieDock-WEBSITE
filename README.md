# MovieDock Launchpad

Act as a Senior UI/UX Designer and Web Developer. Build a high-end, conversion-focused landing page for an Android App named 'MovieDock'.

Visual Identity:
Follow a 'Cinematic Noir' aesthetic. Background: #000000. Accent color: #E50914 (Netflix Red). Use Glassmorphism for cards and navbar.

Structure:

Hero Section: Centered heading 'MovieDock: Your Ultimate Movie Vault'. A prominent 'Download APK' button with a pulse animation. Add a subtitle: 'No Login. No Streaming. Just Pure High-Speed Downloads.'

Mockup Section: Showcase an Android phone frame showing the app's interface (Cinematic Glass theme).

Live Stats: A section fetching data from Supabase (https://lrjuakelenZmpaqvdzht.supabase.co) to show the 'Total Movies Available' or 'Latest Added'.

Safety Section: Highlight that the APK is safe and privacy-focused.

Installation Steps: Visual guide on how to install an APK on Android.

Tech Requirements:
Use Tailwind CSS for styling and Framer Motion for smooth scroll animations. Ensure the 'Download' button points to a direct APK link hosted on GitHub or Google Drive. Make it fully responsive for mobile and desktop."
