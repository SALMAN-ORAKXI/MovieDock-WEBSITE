## 🌟 About MovieDock

MovieDock is developed using Flutter and Dart, with a focus on a cinematic, mobile-first entertainment experience.

The project combines modern application development practices with a clean interface, movie discovery, streaming, and offline viewing capabilities.

### ✨ Key Features

- 🎥 **Movies & TV Series** — Explore entertainment content in one place.
- 🇹🇷 **Turkish Dramas** — Discover Turkish drama content.
- 🇰🇷 **Korean Dramas** — Explore Korean entertainment.
- 🔎 **Search & Discovery** — Find content using search and category filters.
- ▶️ **Online Streaming** — Watch available content through supported playback links.
- 📥 **Offline Downloads** — Download supported content for offline viewing.
- 🔐 **Private Offline Vault** — Access downloaded content within the app.
- 🎨 **Premium Dark UI** — A modern, cinematic interface with elegant styling.
- ⚡ **Performance-Focused Development** — Built with Flutter for a responsive experience.
- ☁️ **Backend Integration** — Uses Supabase for supported database and content metadata operations.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following tools:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio
- Android SDK
- Git
- A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd moviedock
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Configure Backend Credentials

If your version requires Supabase, configure the project using your own Supabase project URL and public/publishable client key.

Never commit private service-role keys, database passwords, or other secrets to GitHub.

### 5. Run the Application

Connect an Android device or start an emulator.

```bash
flutter run
```

### 6. Build an Android APK

```bash
flutter build apk --release
```

The generated APK is normally available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```

**Note:** Build requirements may vary with the Flutter SDK, Android Gradle Plugin, and dependencies used by your checkout.
